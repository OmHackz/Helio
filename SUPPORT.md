# Support

Need help with HelioMC? Here is where to look.

## Read first

- [README](README.md) — install, commands, Ely.by sign-in, troubleshooting
- [BUILD.md](BUILD.md) — building from source and fork-specific notes
- [CONTRIBUTING.md](CONTRIBUTING.md) — development setup and pull requests
- `helio help` — quick command guide
- `helio ref` — full command reference
- `helio version` — version and runtime information

## Ask a question

Use [Discussions](https://github.com/OWNER/REPO/discussions) for open-ended
questions, setup help, and ideas. If Discussions are not enabled yet, open a
question issue with the **Question** template.

Include:

- `helio version`
- Your OS and architecture
- What you tried and what happened
- Relevant logs, with tokens and personal paths removed

## Report a bug

Open an issue with the **Bug report** template. Search existing issues first.

## Request a feature

Open an issue with the **Feature request** template. Describe the problem before
the proposed command or flag.

## Security issue

Do **not** open a public issue. Follow [SECURITY.md](SECURITY.md).

## Ely.by account issues

HelioMC only performs the OAuth flow. For account recovery, passwords, skins, or
Ely.by service outages, use [Ely.by help](https://ely.by/help).

## Minecraft, Java, and mod issues

- Vanilla/Mojang account or game issues: [Minecraft Help](https://help.minecraft.net/)
- Java: [Adoptium](https://adoptium.net/) or your distribution's packages
- Mods and modpacks: the mod author or [Modrinth](https://modrinth.com/)

## Response expectations

This is a volunteer project. Issues and pull requests are reviewed when time
allows. Clear reports with reproducible steps are handled fastest.

## Be kind

All support spaces follow the [Code of Conduct](CODE_OF_CONDUCT.md).
